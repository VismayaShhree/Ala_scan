# Bow & Arrow Accordion Speech Practice (Reels)

This template is for **practice and speaking style**, not a fixed script. It helps you shorten, refine, and then expand your message while removing unnecessary words and fixing grammar.

## Workflow Overview
1. **3-minute rep (full version)**
2. **1-minute rep (compressed using feedback from 3-minute rep)**
3. **30-second rep (compressed using feedback from 1-minute rep)**
4. **Extract the main message (from 30-second rep)**
5. **Reverse accordion:** 30 seconds → 1 minute → 3 minutes using the main message as the core.

## Posting Template (Use this format every time)
```
🏹 Arrow (main focus/essence) – <short phrase>
🔖 Bookmark 1 – <1–3 words>
🔖 Bookmark 2 – <1–3 words>
🔖 Bookmark 3 – <1–3 words>
📝 Notes – <brief observations>
🔄 Self-feedback – <exactly 10 words>
```

## How to Use Self-Feedback
- After the **3-minute rep**, write your **exactly 10-word** feedback.
- Use that feedback as the **only correction target** for the **1-minute rep**.
- After the **1-minute rep**, create a new **10-word** feedback.
- Use that feedback as the correction target for the **30-second rep**.
- After the **30-second rep**, write the **main message** in one sentence.

## Main Message Rule
- Your main message should be **one sentence**, **clear**, and **shareable**.
- Start the reverse accordion with that sentence as your core idea.

## Quick Tips (Clarity, Grammar, and Focus)
- **Say one idea per sentence.** If you add a second idea, split it.
- **Cut filler words:** “actually,” “basically,” “kind of,” “you know.”
- **Use active voice:** “I help people improve speaking” vs. “Speaking is improved.”
- **Avoid vague nouns:** replace “thing” or “stuff” with a real word.
- **Check verb tense consistency** (past vs. present).
- **Use simple connectors:** “because,” “so,” “but,” “however.”
- **End with purpose:** What should the listener remember or do?

## Alternative Word Ideas
- **Important:** key, vital, crucial
- **Problem:** issue, challenge, obstacle
- **Help:** guide, support, improve
- **Improve:** sharpen, strengthen, refine
- **Clear:** simple, direct, focused

## Example (Filled)
```
🏹 Arrow (main focus/essence) – Speak with clarity
🔖 Bookmark 1 – Cut filler
🔖 Bookmark 2 – One idea
🔖 Bookmark 3 – Strong ending
📝 Notes – I repeated ideas and wandered before reaching the point.
🔄 Self-feedback – I rambled, used fillers, and ended without a clear takeaway.
```
